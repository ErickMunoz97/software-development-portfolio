The apps were created during programming coursework; the versions here were organized, documented, and given targeted maintenance fixes in October 2026. ### What is original and what changed?

These projects began as student assignments written in Spanish. Technical cleanup, documentation, defensive validation and example data have been added with AI assistance. This portfolio is **not** a claim that every line in the current revision was written unaided or that every legacy application currently builds on modern software. See [MAINTENANCE_NOTES.md](MAINTENANCE_NOTES.md) and each project README for specifics.

### Getting started

Each folder is a separate project with a README, prerequisites, and relevant instructions. The Java programs are the quickest to run. Xamarin.Forms is an **end-of-support framework** and may require legacy tooling; no current mobile binaries are offered.
